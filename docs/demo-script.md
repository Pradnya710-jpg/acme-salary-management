# 3-minute demo

1. Open dashboard: show 10,000 employees and country/department salary insights.
2. Open Employees: search an employee and demonstrate pagination.
3. Filter by country and department.
4. Open employee details and show salary history.
5. Update salary with an effective date and show the new history record.
6. Briefly show the repository: requirements, architecture, tests and incremental commits.
7. Run the test command and show the passing result.
