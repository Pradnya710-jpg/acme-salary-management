# ACME Salary Management

Employee salary management application built for the ACME Salary Management assessment.

## Tech Stack

### Backend
- Node.js
- TypeScript
- Express.js
- PostgreSQL
- JWT
- bcrypt

### Frontend
- React
- TypeScript
- Vite
- React Router

## Features

- HR authentication
- JWT-based authentication
- Role-based access
- Employee listing
- Employee search
- Employee pagination
- Employee details
- Salary history
- Salary updates
- Dashboard
- 10,000 employee seed data
- Logout
- Protected routes
